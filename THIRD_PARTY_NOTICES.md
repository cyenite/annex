## Software annex runs

annex does not include these programs. It runs the copies installed on your system, and
`annex setup` installs them through your distribution's package manager, which ships each with
its own license.

### Redroid

Container mode runs Android images from the Redroid project.

- Project: https://github.com/remote-android/redroid-doc
- License: Apache License 2.0. The images include many third-party Android components under their
  own licenses; Redroid's kernel modules are under the GNU GPL version 2.

### scrcpy

Screen and app windows, and the desktop bridge's clipboard sync, use scrcpy and its device server.

- Project: https://github.com/Genymobile/scrcpy
- License: Apache License 2.0

```

Copyright (C) 2018-2026 Romain Vimont
```
